📐 수면부채 지수 감쇠(Exponential Decay) 공식

기존의 단순 수면부채는 14일 전의 피로와 어제의 피로를 동일하게 취급하지만, 인간의 생체 리듬은 최근 며칠의 수면에 훨씬 민감하게 반응합니다.

Cumulative Debt = Σ [ e^(-0.15 × d) × (Sleep Need - Effective Sleep_d) ]
(d=0 어제 가중치 1.00 ➔ d=3 가중치 0.64 ➔ d=13 가중치 0.14)

🧬 유효 회복 수면 (Effective Restorative Sleep)

단순히 침대에 누워있던 시간이 아니라, 뇌와 근육을 실질적으로 회복시킨 수면 단계(깊은 수면 + 렘 수면)와 중간 깬 시간(각성도)을 반영하여 유효 수면을 보정합니다.

Effective Sleep = Actual Sleep × (Efficiency / 100) ×
[ 1.0 + 0.25 × (Deep/Total) + 0.15 × (REM/Total) - 0.2 × (Awake/BedTime) ]

⏰ 서카디안 오후 슬럼프 (Circadian Dip)

기상 후 7~9시간 뒤에는 생체 시계에 의해 심부 체온이 일시적으로 하강하며 강한 졸음이 찾아옵니다. 이때 수면 부채가 누적되어 있다면 극심한 인지 저하가 발생하므로 15분 파워냅이 필수적입니다.
