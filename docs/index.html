🧬 유효 회복 수면 (Effective Sleep Quality)

단순 누워있던 시간이 아니라, 뇌파가 느려진 깊은 수면과 기억을 정리하는 렘 수면에 가중치를 부여하고, 밤중 깬 시간(각성도)을 페널티로 감점합니다.

Effective Sleep = Actual Sleep × (Efficiency / 100) ×
[ 1.0 + 0.25 × (Deep/Total) + 0.15 × (REM/Total) - 0.20 × (Awake/BedTime) ]
